| 2026-10-17 | [Godot vs Unity for agent-driven development](2026-10-17-godot-vs-unity.md) | The agent loop is 30–40× faster in Godot (0.14 s against 4–5 s a script run; 0.6 s against ~13 s a correct screenshot after an edit). Unity's runtime is ~3× faster (0.58 against 1.97 ms a frame), but both are far inside budget. Kernel per character-frame: Python 263 µs, GDScript 71, C# 17. Unity batch-editor captures of a lit URP scene with SSAO rendered wrong. Second pass, a real export: binding, collider fit and IK accuracy equal to the millimetre; Godot's glTF import right with no work (Unity's FBX lost the ortho camera and shifted colours); Unity's navigation 4–8× faster and deterministic (a Godot agent got stuck in a fast-forwarded sim with a moving obstacle); overlap queries ~0.4–0.8 µs in both. |
